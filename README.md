# Laboratorio-4-Polimorfismo
AcopioGT es una cooperativa que recibe las cosechas de sus asociados, las almacena en sus bodegas y las despacha a compradores. Hasta ahora usaban una hoja de cálculo, pero la variedad de productos y de reglas ha crecido tanto que los errores en los pagos a los productores ; incluso se ha despachado producto vencido.
